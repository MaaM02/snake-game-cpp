# snake-game-cpp
Juego de la Serpiente (Snake Game) desarrollado en C++ utilizando Programación Orientada a Objetos (POO), herencia, punteros y estructuras de datos dinámicas avanzadas (listas doblemente enlazadas creadas desde cero). Incluye interfaz gráfica con Windows Forms (C++/CLI) y renderizado mediante doble buffer para evitar el parpadeo de pantalla.
